# Travel Guide Website

Welcome to **Travel Guide** – a sleek, React-based frontend travel platform that lets users explore, discover, and plan unforgettable trips. Though it's currently frontend-only, the project is built with scalability in mind, and can easily evolve into a full MERN stack application.

## Get Started

### To run this React project locally:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/VishalRN/React-Travel-Guide.git
   cd React-Travel-Guide
   ```
2. **Install dependencies**:

   ```bash
   npm install
   ```
3. **Start the development server**:

   ```bash
   npm start
   ```
4. **Open in your browser**:

   ```bash 
   http://localhost:3000
   ```
